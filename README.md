# API Pearl Thoughts 🚀

 Project Overview
API Pearl Thoughts is a simple backend REST API project built using Node.js and Express.
The main goal of this project is to understand how server-side applications work, how APIs are created, and how requests and responses are handled.

This project is beginner-friendly and focuses on backend fundamentals such as:
- Setting up an Express server
- Creating API routes
- Understanding HTTP methods
- Managing project using Git and GitHub

---

## 🛠️ Technologies Used
- **Node.js** 
- **Express.js** – Web framework for building APIs
- **Git** – Version control system
- **GitHub** – Code hosting platform
